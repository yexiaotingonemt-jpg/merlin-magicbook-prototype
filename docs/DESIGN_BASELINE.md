## 二、单轮流程

- 单轮固定6章：第1章15个事件、第2章20个事件、第3章固定首领、第4章30个事件、第5章10个事件、第6章战前整备与固定终极首领。
- 普通章开始时按照总权重1000独立放回抽取整章事件；展示位最多3个，进入展示位后即从池中移除。
- 每处理1个事件，其他有限倒计时事件减1，然后结算自燃或威胁升级，最后补满展示位。
- 经验、休息室、升级事件无限倒计时；元素4、图书馆2、转化3、整理4；怪物和玩家事件固定2。
- 正面事件倒计时归零后消失；怪物和玩家事件按100%/120%/140%升级，Lv.3固定占位。
- 完成章节进入下一章前补满生命。第3、6章可在挑战首领前查看信息和调整魔法书。

## 三、角色与元素

| 项目 | Lv.1 | 每级成长 |
|---|---:|---:|
| 最大生命 | 250 | +20 |
| 法术攻击 | 100 | +8 |
| 法术防御 | 50 | +4 |
| 命中/闪避 | 50/80 | 不自动成长 |
| 暴击/抗暴 | 100/50 | 不自动成长 |

- 升级需求：`80+40×（当前等级-1）`，升级立即回复40生命。
- 每次重新进入法师塔实际拥有2个起始元素；编排上限为Lv.1时3个、Lv.3时4个、Lv.5时5个，硬上限5。
- 战斗元素池基础容量为起始元素上限+2，即5/6/7。
- 每次重新进入法师塔，从火、水、风随机选2系，以2页+1页形成3张Lv.1初始战斗书页，两系各有1个起始元素、另留1个可成长空位，仓库为0。
- 探索界面提供下一级生命、法攻、法防、起始元素上限和战斗元素池上限预览。
- 战斗牌库最多装订10页，每种同名咒语只装订1页；未满10页时仓库书页可自由装入，移回仓库需要整理次数。获得新书页时若战斗牌库已满，该页自动进入仓库。

## 四、战斗公式

```text
有效防御 = 防守方法防×（1-百分比减防）×（1-百分比穿透）-固定穿透
防御修正 = 攻击方法攻÷（攻击方法攻+有效防御）
闪避率 = clamp（防守方闪避-攻击方命中，0%，80%）
暴击率 = clamp（攻击方暴击-防守方抗暴，0%，75%）
暴击伤害 = 200%
```

- 卡面伤害乘0.25，固定/次数治疗乘0.50，法防型护盾乘0.35。
- 伤害和治疗完成其他结算后再乘独立的0.95～1.05微方差。
- 元素效果保留40%～300%偏态方差，期望100%。
- PVP标准目标为每名玩家约20次行动；普通PVE为玩家约10次行动。
- 普通怪物使用同级玩家60%生命、70%法攻、50%法防与70点普通攻击卡面值；固定首领基础属性与同级玩家相当。

## 五、卡池

- 91张战斗咒语：50张单系、12张复合、17张通用、12张完全消耗型。
- 8张无限成长被动卡不进入战斗牌库。
- 六张大型生成牌：`FI-09`、`WA-09`、`WI-11`、`EA-09`、`LI-09`、`DA-09`，分别增加3个对应元素。
- 大型生成牌只参与正常随机翻页，没有元素呼应，也不能被索引、重演、书签或权重效果直接选中。
- 战斗牌库不放回翻页，整轮翻完后洗回；元素足够自动完整施法，否则发动残响且不消耗元素。
- 多段牌逐段重新选择当前生命最低的敌人，击杀后自动转火；指定多目标牌在开牌时仅有1名敌人，改为发动完整施法限定的逐段递增、单体聚焦或半血处决补偿，不能与多目标接续同时生效。
- 战斗左右信息区使用生命、护盾、法攻、元素、Buff/Debuff的对称结构，状态支持展开查看机制说明；多敌人时完整信息跟随当前最低生命目标。
- 中央同时显示双方当前书页。我方书页完整列出支付、完整施法、残响、目标和本次发动类型；无魔法书NPC显示无额外卡牌效果的普通攻击页。PVP镜像可查看快照装订列表，但在敌方卡牌结算接入前明确标注仍使用基础术式。

## 六、原型已落地但仍需实测的部分

- 元素事件权重为第1/2/4/5章`80/70/40/20`，全塔生成期望为4.00次（自燃前），用于覆盖3次扩容和约1次换系。
- 六类怪物克制被动已经进入战斗，强克制“逆流诅咒”只会出现在高等级或首领模板。
- 元素事件采用六系自由选择；转化事件采用单张、随机异系同消耗、保留等级与装订位置。
- 商店当前只出售已定案的法攻+4、法防+2、生命+10三类商品，基础价格均为100；元素扩容在新效果未定案前不投放。
- 当前首测重点是PVP 18～22次行动分布、PVE 9～11次行动分布、第四章约164点构筑续航缺口，以及怪物被动是否形成检验而非硬封锁。
